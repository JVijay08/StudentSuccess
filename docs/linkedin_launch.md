# LinkedIn launch draft

I built StudentSuccess, a procrastination-aware workload and action-planning prototype for high-school students.

Most planners tell students what is due. I wanted to explore a more useful question: **what should I start now, and why?**

StudentSuccess combines planned start times, deadlines, task difficulty, interest, past starting behavior, and a four-year course-load view. Its recommendations are rule-based and show their reasoning instead of presenting an unexplained score.

The prototype includes:

- a one-click fictional demo workspace;
- explainable next-action recommendations;
- planned-versus-actual task timing;
- course workload, prerequisite, AP, and IB reference data;
- accessibility and focus settings; and
- data export and account controls.

This is still a prototype and is **not ready for real student information**. Please use fictional data only. The free demo server may also take up to a minute to wake after inactivity.

Live demo: https://studentsuccess.onrender.com/

Source code: https://github.com/JVijay08/StudentSuccess

I would especially appreciate feedback on one question: **Does the next-action recommendation feel understandable and useful?**
