# Workspace refresh - October 2, 2026

Preserves the cream graph paper, navy/blue controls, gold accents, notebook depth,
themes, and reduced-motion support. Adds a short gold divider, tighter task-card
spacing, clearer titles, a two-column task form, and consistent mobile spacing.

Routine task, course, search, and preference forms no longer require repeated privacy
checkboxes. Registration guidance remains; calendar import and backup restoration
keep their review, and AI requests keep explicit third-party sharing consent.

Settings uses native collapsible groups. Timing history is expandable in both
dashboard modes. Course filtering has one Apply action. Optional task time,
recurrence, custom subject, and advanced planning fields use progressive disclosure.
All controls remain available with keyboard or without JavaScript.

AI assignment drafting lives inside Tasks instead of a new navigation tab.
Assignment text produces editable steps, with deadline and estimate supplied by the
student. Review creates the parent assignment and selected subtasks together.
Existing assignment breakdown remains available. Both share quotas and consent.
